# Periódico Digital: Deadlock News

## Descripción
Página web de noticias inspirada en la maquetación y estructura visual del diario digital MARCA, enfocada en la actualidad, guías tácticas, análisis de héroes y escena competitiva del videojuego **Deadlock** (Valve).

## Características principales
* **Cabecera y navegación:** Barra superior con identidad del medio y menú de navegación con cinco secciones temáticas.
* **Noticia principal:** Artículo destacado centrado en el héroe *Pocket* con imagen principal, titular y texto introductorio.
* **Noticias secundarias:** Rejilla de seis noticias organizadas en columnas responsivas mediante el sistema Grid de Bootstrap 5.
* **Barra lateral:** Sección con el ranking de las noticias más leídas y bloque destacado.
* **Pie de página:** Información institucional, autoría y año de publicación.

## Tecnologías utilizadas
* HTML5
* Bootstrap 5.3 (vía CDN)
* Git y GitHub para el control de versiones
